# 00. Overview

## 0.1 한 줄 정의
t4e는 터미널 안에서 **큐레이션된 앱/툴을 검색·설치·실행**하고, **tmux/zellij 분할 워크스페이스**로 "한 번에" 띄우는 TUI 기반 대시보드다.

## 0.2 핵심 가치
- 발견(Discover): "뭐 설치하지?"를 팩/검색으로 해결
- 설치(Install): 여러 툴을 큐레이션된 모음으로 원키 설치
- 실행(Run): 분할 워크스페이스로 바로 사용(특히 엔터테인먼트/파일/펀)
- 확장(Extend): 필요 시 개발자 도구 및 코딩 에이전트(Claude/Codex/OpenCode) 추가

## 0.3 제품 포지션
- "Raycast for Terminal" + "Starter Pack(엔터테인먼트 중심)" + "Workspace Launcher(tmux/zellij)"
- 링크 모음(디렉터리)이나 단일 런처보다, **설치→실행→워크스페이스**까지 한 흐름으로 제공

## 0.4 사용자 범주
- Primary: 터미널을 쓰는 일반/파워유저(엔터테인먼트/파일 관리 체감)
- Secondary: tmux/zellij 사용자(작업공간 템플릿)
- Tertiary: 개발자(IDE/에이전트 옵션 설치)

## 0.5 v0.1 범위 요약
